# GTA VI — Trophy Guide & Tracker

An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI (1 platinum, 2 gold, 6 silver, 46 bronze; 28 hidden; 0 online).

- **Checklist tracker** — tick trophies as you earn them; progress saves in localStorage, with export to a JSON file and import back.
- **Filters** — by kind (story, missable, collectibles, activities, robberies, exploration, money, side & misc, online) and by grade, plus text search and an earned-only view.
- **Spoiler setting** — hides the names, descriptions and guides of story trophies until they are earned.
- **Roadmap to the platinum** — the 3-step plan (story 60–80 h, 100% checklist ~100 h, Strangers & Freaks + cleanup ~10 h), with per-step trophy counts, the one missable trophy flagged, and save/cheat warnings.
- **Cited guides** — every trophy has a guide in our own words with its sources named beside it. GTA VI is unreleased, so steps taken from analogous GTA V / GTA Online mechanics are labelled as analogy and marked unconfirmed for VI, and the five hidden trophies no cited source has solved are marked unsolved instead of guessed.
- **Sources** — the official list as Exophase and PSNProfiles published it (cross-checked by PlanetGTA6 and GTADB); conditions and counts from PowerPyx, GameMapa, Push Square, KeenGamer, Mobalytics, Insider Gaming, GTASpotter and GameTrek; GTA V analogies from PixelForge, Neoseeker and GameTree. Each trophy names its own sources beside its guide.

Run it with any static server: `node serve.ts`, then open http://localhost:8080. No network at runtime — everything the app loads is a file under `app/`.
